## 📌 Sobre a plataforma

O **SQLBolt** é um site gratuito, em inglês, com lições curtas e exercícios interativos que rodam direto no navegador. Cada lição explica um conceito de SQL e, logo em seguida, propõe exercícios com resultado imediato, o que ajuda a fixar o conteúdo na prática.

## 🗂️ Como organizo os arquivos

Um arquivo por lição, numerado na mesma ordem do site:

```
sqlbolt/
├── lesson-1-SELECT-queries-101.md
├── lesson-2-queries-with-constraints-pt1.md
├── ...
└── README.md
```

Cada arquivo traz:

- 📝 Resumo do conceito com minhas palavras
- 💻 Queries resolvidas nos exercícios
