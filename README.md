## 🎓 Plataformas de estudo

### 🔖 SQLBolt

O [**SQLBolt**](https://sqlbolt.com) é um site gratuito com lições curtas e exercícios interativos, ideal para fixar os fundamentos de SQL direto no navegador.

- 🌟 Aprendizado passo a passo, uma lição por vez
- 🌟 Exercícios práticos com resultado imediato
- 🌟 Ótimo para consolidar `SELECT`, `JOIN`s, agregações e mais

📂 **Na pasta:** anotações de cada lição e as queries resolvidas nos exercícios.

### 🧩 LeetCode

O [**LeetCode**](https://leetcode.com) é uma das plataformas mais conhecidas para praticar problemas de programação, e a seção de **banco de dados** reúne desafios de SQL em vários níveis de dificuldade.

- 🌟 Problemas de nível fácil, médio e difícil
- 🌟 Treino de raciocínio, ótimo para entrevistas técnicas
- 🌟 Prática com `JOIN`s, subconsultas, CTEs e funções de janela

📂 **Na pasta:** uma solução por arquivo `.sql`, nomeada com o número e o título do problema (ex.: `175-combine-two-tables.sql`).

### 📚 SQL Essencial (EducaDados)

O curso **SQL Essencial**, da plataforma **EducaDados**, é a base teórica e prática da minha jornada, cobrindo os conceitos fundamentais da linguagem.

📂 **Na pasta:** anotações por módulo/aula e os exercícios feitos durante o curso.
